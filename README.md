# Pedro Henrique - Portfolio

Um portfólio moderno e responsivo desenvolvido para apresentar projetos, habilidades e serviços. Site otimizado para performance, SEO e experiência do usuário.

## 🎯 Características

- ⚡ **Performático**: Tempo de carregamento inferior a 1 segundo
- 📱 **Responsivo**: 100% adaptável a todos os dispositivos
- 🔍 **Otimizado para SEO**: Estrutura semântica e meta tags
- 🎨 **Design Moderno**: UI limpa e intuitiva com Tailwind CSS
- ⌨️ **TypeScript**: Código tipado e seguro
- 🚀 **Vite**: Build rápido e dev experience otimizado

## 🛠️ Tecnologias

- **React** 19.2+ - Biblioteca UI
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Lucide React** - Ícones
- **ESLint** - Linting

## 📦 Instalação

1. Clone o repositório:

```bash
git clone https://github.com/plyrio/portfolio-novo.git
cd portfolio-novo
```

2. Instale as dependências:

```bash
npm install
```

## 🚀 Como usar

**Desenvolvimento:**

```bash
npm run dev
```

O site será aberto em `http://localhost:5173`

**Build para produção:**

```bash
npm run build
```

**Preview da build:**

```bash
npm run preview
```

**Verificar linting:**

```bash
npm run lint
```

## 📁 Estrutura do Projeto

```
src/
├── components/       # Componentes reutilizáveis
│   ├── layout/      # Header, Footer, Navigation
│   ├── sections/    # Seções da página (Hero, About, Projects, etc)
│   ├── ui/          # Componentes UI genéricos
│   └── lib/         # Utilitários
├── data/            # Dados estáticos (projetos, skills, etc)
├── hooks/           # React hooks customizados
└── App.tsx          # Componente principal
```
